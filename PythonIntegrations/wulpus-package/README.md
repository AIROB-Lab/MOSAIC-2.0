# Wulpus Python package

This directory packages the Wulpus Python source used by MOSAIC. The retained
source originates from the [pulp-bio/wulpus](https://github.com/pulp-bio/wulpus/tree/main/sw)
project and is distributed under the accompanying Apache-2.0 license.

Only `src/wulpus` is source. Generated `build` and `*.egg-info` directories are
intentionally excluded from the public repository.
