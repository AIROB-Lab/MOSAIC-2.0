# MOSAIC documentation theme

This template layers a custom shell over DocFX's default article and API rendering.
`Documentation/docfx.json` selects `default` followed by `templates/mosaic`.

- `layout/_master.tmpl`: header, sidebar, article layout, search dialog.
- `styles/mosaic.css`: typography, colours, responsive layout, and code styles.
- `styles/mosaic.js`: guide/API navigation, local search, heading outline, copy buttons,
  and mobile navigation. Syntax highlighting uses DocFX's bundled vendor script.
- `ManagedReference.extension.js` and `partials/class.header.tmpl.partial`: place
  class-level JSON examples beside model descriptions, before inherited members.
  Examples come from C# XML comments; ordinary DocFX builds render them without a
  separate generation step. Non-JSON examples retain their normal Examples section.
- `Documentation/index.md`: home page content and entry points.

Brand assets come from the original MOSAIC site at https://airob-lab.github.io/:
`styles/mosaic-logo.png` is an unchanged copy of its `images/logo.png`.
The dark palette follows its `styles/config.css`: page `#1f1f23`, sidebar `#292b30`,
header `#18191c`, text `#e1e1e1`, cyan accent `#00b0f4`, hover `#2ec4ff`.
The logo is also used as the favicon and is bundled locally for offline use.

The guide menu reads the generated `docs/toc.json`, so update `docs/toc.yml` to change
its entries. API navigation joins generated `api/toc.json` with `api-blocks.json`.
The latter is generated by `Documentation/generate_api_blocks.py` between metadata
extraction and site rendering in `Documentation/build.ps1`. Concrete BaseBlock classes,
catalogue/factory registrations, selector associations and naming conventions supply
the groups. No manual navigation entry is needed for a normal new block. Existing
guides supply their titles and links; blocks without guides link to the catalogue.
`api-block-overrides.json` adds unusual UI/helper associations. Unassociated types
remain in Shared APIs. See the building-documentation guide for the override schema.

Initial mappings were checked against the block guides, BlockTemplateSelector, model/UI
source files and dedicated device-helper namespaces. An association is not a claim
that every related card or view model is selected at runtime. For example, the
SinGenerator card binds to its model directly. `check_docs.py` validates mapping
coverage and UID/link targets against the generated API index.

Search reads the generated `index.json`
on first use; the theme does not require an external search service or CDN assets.

Build with `./Documentation/build.ps1` from the repository root and serve
`Documentation/_site` over HTTP. Opening HTML directly as `file://` prevents browsers
from fetching the navigation and search indexes.

After changing the theme, check the home page, a long guide with code and tables, and an
API class. Verify search, code copying, section links, and the menu at narrow widths.
