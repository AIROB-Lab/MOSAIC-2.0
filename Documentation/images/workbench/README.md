# Workbench teaching media

These assets were selected from project teaching recordings and reviewed in
September 2026. They are recordings of a desktop teaching session, not captures
of the downloadable signal-processing or classifier examples.

| Documentation asset | Content |
|---|---|
| connect-blocks.gif | Connecting a generator to two Function blocks |
| block-controls.gif | Editing Function parameters |
| pop-out.gif | Opening a visualization in a separate window |
| workbench.png | Workbench overview with cards and a connected graph |
| myo-connection.png | Myo connection controls |
| labelled-capture.png | Trigger-based labelled capture controls |

Each retained GIF's matching PNG is an unscaled still frame: connect-blocks 165,
block-controls 509, and pop-out 161 (zero-based). All previews retain the
original 2560 × 1392 resolution; no cropping, upscaling or generated detail is used.
The GIFs and two supplied PNG screenshots are copied unchanged. Animations remain
opt-in; a full-size original link opens in a new tab and works without JavaScript.
The original add-block recording is not distributed because its palette showed
integrations excluded from the public release.

The guide text was adapted against current source behavior. In particular, Clock
does not start every source; the compact monitor slider changes display height;
editor connection checks do not validate arbitrary payload shapes; pipeline saving,
generic recording and labelled segment export have different persistence behavior.
The capture screenshot shows EMG gesture labels, not Learning Lab's Low/High labels.
